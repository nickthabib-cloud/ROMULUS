## Answer to the owner's question

**Neither agent mode reaches or concludes anything that changes the report relative to model-off.**

- All three hunts report and surface the same 97 items, with the same signatures and lanes.
- Every recall, precision, noise and citation metric is identical.
- No opportunity is hit in one mode and not another.
- Neither mode produced an admitted item. Escalation cannot change a candidate's lane, so it marks the case escalated without changing what the report contains.

### What the agents did beyond the sweep

**Deterministic mode**
- 59 complete pivots, 4 of which retrieved a gold action/outcome record. They reached 2 observable opportunities (recon_scan, persistence), both already surfaced by the sweep.
- One case was parked "deterministic investigation complete". Its 34 seed candidates are all attacker-caused: 15 Tier A hits and 19 adjudicated `true_unlisted`.
- No escalation.

**Model mode**
- 22 complete pivots, one of which retrieved a gold record (recon_scan, already surfaced).
- 9 cases escalated:
  - 3 on gold candidates, covering 4 opportunities (persistence, privesc, recon_scan ×2). One of these recon_scan opportunities is only a lead in the sweep, so the model's escalation does point at something model-off leaves at lead, but the report lane is unchanged.
  - 6 on candidates the custodian had adjudicated benign. These are false escalations.
- So 3 of 9 escalations were correct.

## Caveats

- One run per mode, and n = 22 observable opportunities. The model is stochastic, so there is no variance estimate for it.
- **Model-mode time and cost.** The hunt's wall time and cost include a mid-run HTTP-400 schema fix and redeploy (audit: `hunt.partial` then `hunt.resume`), so total hunt time (+708.5 s) is not a clean agent cost. Model-call time (382.6 s over 33 calls) is. One call failed with HTTP 400, and two were constraint defects (an evidence alias not allowed for the chosen option). One deterministic fallback occurred.
- **Time to first actionable** differs by up to 7 s across modes. That is sweep-timing noise, because the agent starts after the sweep.
- **Pivot reach** means a pivot retrieved a gold action/outcome record. It is a lower bound (result-digest event IDs plus raw records whose first retrieving task was the pivot), and it never counts as recall.
- **Seed accounting** comes from the hunt's agent summary. A "concluded" seed only means its case reached a terminal status. Deterministic mode concluded 34 seeds and left 63 unworked; model mode concluded 50 and left 47.
- These hunts are the v2 replicas of runs 1 and 3 (v1 investigator). The off arm matches run 1 on every scored quantity except timing (wall clock).
