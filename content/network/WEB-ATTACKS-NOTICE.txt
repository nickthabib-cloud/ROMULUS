ROMULUS implements a bounded subset of these grammar concepts with its own
token patterns, decoding, evidence semantics and disk aggregation. These are
modified adaptations, not the complete upstream rules or a WAF engine.

User-agent marker selection adapts two Sigma rules:
Suspicious User-Agents Related To Recon Tools, by Nasreddine Bencherchali
(Nextron Systems) and Tim Shelton,
https://github.com/SigmaHQ/sigma/blob/master/rules/web/webserver_generic/web_susp_useragents.yml
and Hack Tool User Agent, by Florian Roth (Nextron Systems),
https://github.com/SigmaHQ/sigma/blob/master/rules/web/proxy_generic/proxy_ua_hacktool.yml
Both are licensed under Detection Rule License (DRL) 1.1:
https://github.com/SigmaHQ/Detection-Rule-License/blob/main/LICENSE.Detection.Rules.md
Matched tool observations retain the authors' attribution in their notes.

Further tool-name markers (Nuclei, Hydra, Medusa, masscan, OpenVAS, Arachni and
others) are factual identifiers from each tool's own published source or
documentation, listed in web_attacks_sources.json. Tool names and URLs are
identifiers; no tool source code was copied.
